# Project Images

Place your project thumbnail images in this folder.

## Required Images:

- `project-1-thumb.jpg` - Thumbnail for Project Title One
- `project-2-thumb.jpg` - Thumbnail for Project Title Two
- `project-3-thumb.jpg` - Thumbnail for Project Title Three
- `project-4-thumb.jpg` - Thumbnail for Project Title Four
- `give-in-thumb.jpg` - Thumbnail for Give In video project
- `quail-thumb.jpg` - Thumbnail for Quail video project

## Recommended Size:
- Width: 800px
- Height: 600px
- Format: JPG or PNG
- Aspect Ratio: 4:3

## Note:
If an image is not found, the page will automatically fallback to a placeholder image from placehold.co.
